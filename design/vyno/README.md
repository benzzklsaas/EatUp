# Vyno brand & mobile UI concept

A high-fidelity UI/UX design presentation exploring **Vyno** — a rebrand
concept for EatUp's order-ahead / commission-free pickup platform.
Built for an investor / designer / developer audience.

**Live presentation:** https://claude.ai/code/artifact/9becc274-c7bd-4ca1-9870-2b0bc4daa901

Brand motif carried through every screen: confident blue, organic bubble
shapes, warm food imagery, generously rounded mobile-app UI.

## What's in this folder

These are the source files for a multi-artboard Claude Design canvas
(`.dc.html` = one artboard each; `canvas.json` lays them out across three
pages). The published presentation above is generated from these files —
edit them and re-seed to update it.

- `Main.dc.html` — cover / title slide
- `Brand.dc.html` — logo, color, type, bubble motif, iconography, shape system
- `Onboarding.dc.html`, `Home.dc.html`, `MenuDetail.dc.html`,
  `Checkout.dc.html`, `Tracking.dc.html`, `Success.dc.html` — the core
  order-ahead mobile flow, as realistic phone-frame mockups
- `Landing.dc.html` — marketing website hero (consumer + restaurant-partner)
- `Dashboard.dc.html` — restaurant partner order dashboard
- `canvas.json` — artboard layout, pages, launch view

## Notes / assumptions

- No real photography or brand assets were supplied, so food imagery is
  illustrated (layered blob shapes) rather than photographic.
- These are static high-fidelity mockups, not a clickable prototype.
- This is a concept/presentation deliverable — it is not wired into the
  Next.js app in this repository.
